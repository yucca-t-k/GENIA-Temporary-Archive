# GENIA-Temporary-Archive
The official GENIA Corpus (<https://geniaproject.org>) website appears to be currently inaccessible, so I have uploaded the files I have stored locally to this repository. Please note that this repository may be removed once the website is back online.

The Meta-Knowledge Corpus can be found on the NaCTeM site (<https://nactem.ac.uk/meta-knowledge/>).

If you have any data that is not included here and are willing to share it, please let me know via a pull request or opening an issue.
